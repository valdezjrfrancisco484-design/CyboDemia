Privacy & Data Policy

We respect your privacy and are committed to keeping your experience safe and secure while using CyboDemia.

1. Data We Collect

We do not collect personal data such as names, passwords, or emails. We may store basic interaction data like quiz answers and preferences (e.g. language selection).

2. How We Use Data

Any stored data is used only to improve user experience, such as saving language preferences or quiz progress. We do not sell or share data with third parties.

3. Cookies & Local Storage

This website uses local storage to remember user preferences like selected language. No tracking cookies are used for advertising purposes.

⚠ This site uses local storage only for user preferences (e.g. language settings).

4. Security

We use basic web security practices to ensure safe browsing. However, users are encouraged to avoid sharing sensitive information online.

5. User Control

Users can clear stored preferences anytime by clearing browser storage/cache.

6. Trust & Transparency

CyboDemia is built as an educational platform. We prioritize transparency and do not intentionally collect personal sensitive data.

Your privacy matters — No personal data is collected or sold
